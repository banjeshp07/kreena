# Krina Gindra - Luxury Portfolio Website

A premium, modern, and fully responsive website built for **Krina Gindra (Events & Marketing)**, designed with an elegant luxury aesthetic.

## 🔗 Links
- **Live Deployment:** https://kreena-two.vercel.app/
- **GitHub Repository:** https://github.com/banjeshp07/kreena

## ✨ Brand Style & Palette
- **Primary Aesthetic:** Clean luxury look with sophisticated typography.
- **Color Palette:** Rich Black (`#121212`), Cream / Ivory (`#FDFBF7`), and Subtle Gold accents (`#D4AF37`, `#C5A059`).

## 🛠️ Main Sections Included
1. **Hero Section:** Striking typography and high-end brand introduction.
2. **About Section:** Founder/Brand vision and core values (*Uncompromised Luxury, Targeted Impact, Seamless Execution*).
3. **Services Section:** Detailed offerings covering Events, Advertising, Social Media, and Marketing.
4. **Portfolio / Selected Work:** Showcase of iconic projects and case studies.
5. **Contact / Enquiry Form:** Interactive enquiry section with success confirmation.
6. **Footer:** Minimalist luxury footer.

## 💻 Tech Stack
- **React & Vite** for lightning-fast frontend performance.
- **Tailwind CSS (v3)** for styling and responsive layouts.
- **Lucide React** for modern icons.

## 🚀 Setup & Installation Instructions

To run this project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/banjeshp07/kreena.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd kreena
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Run the development server:**
   ```bash
   npm run dev
   ```

5. **Open in browser:**
   Visit `http://localhost:5173` to view the live local site.
